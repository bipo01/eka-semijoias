# Fotos de teste do padronizador

Geradas no ChatGPT em 23/11/2026 (Claude in Chrome), imitando fotos de celular de uma lojista: os casos difíceis para remover o fundo.

- `eka-test-1-corrente`: corrente fina dourada sobre linho bege.
- `eka-test-2-perola`: brincos e pingente de pérola sobre papel branco (branco no branco).
- `eka-test-3-anel-zirconia`: anel dourado com zircônias sobre madeira, fundo com objetos.
- `eka-test-4-brincos-prata`: brincos de zircônia e pulseira fina de prata sobre granito escuro, com a quina de uma caixa.

Uso: `node scripts/measure-standardizer.mjs --photos assets/test-photos` (resultados em `docs/qa/standardizer/`). Não são fotos das peças da ÉKA e não vão para o site.
